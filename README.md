# 小日子記帳

繁體中文的個人收支記帳網頁，以新臺幣（TWD）計算。無需註冊，也不依賴外部服務或套件。

## 啟動

需要 Python 3。於儲存庫目錄執行：

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

在本機瀏覽器開啟 `http://localhost:3000`。也可以使用 `npm start` 執行相同指令。雲端環境需透過平台提供的連接埠存取功能開啟。請透過 HTTP 服務載入網頁；直接開啟 HTML 檔案無法載入 JavaScript 模組。

## 功能

- 新增、編輯與刪除收入及支出，含日期、分類、金額與備註。
- 月份切換、每月收入／支出／結餘及支出分類圖表。
- 搜尋紀錄、依類型與分類篩選，統計維持顯示整個月份。
- 匯出目前月份與篩選結果的 CSV，含 UTF-8 BOM，方便使用試算表開啟。
- 下載完整 JSON 備份，並可匯入還原；還原前會要求確認取代現有資料。
- 瀏覽器分頁間同步更新，以及手機版面與鍵盤操作。

## 資料保存

帳本使用 `localStorage`，只保存在目前瀏覽器、目前網站來源，不會上傳至伺服器，也不會自動同步至其他裝置。換用網址、連接埠、瀏覽器或清除網站資料，都可能無法存取原帳本；無痕模式的資料通常會在關閉後消失。請定期下載 JSON 備份，換裝置時再匯入。備份檔含完整收支內容，請自行妥善保存。

金額最多支援九位整數與兩位小數，內部以整數分運算。單一帳本上限為 20,000 筆，實際容量也受瀏覽器儲存空間限制。儲存失敗會提示，並保留原有資料。讀取既有資料失敗時會暫停寫入，避免覆蓋原始帳本。

此版本為單人使用的本地帳本，不含登入、雲端同步、銀行串接或多人協作。

## 驗證

需要 Node.js 18 以上：

```sh
npm test
```

測試涵蓋金額精度、資料與日期驗證、月份統計、組合篩選、備份解析及 CSV 安全跳脫。沒有第三方 npm 依賴，因此不需要先執行 `npm install`。

若環境已有 Python Playwright 與 Chromium，可在網頁服務啟動後執行瀏覽器整合測試：

```sh
python3 tests/browser_smoke.py
```

此測試使用獨立瀏覽器資料，驗證新增／編輯／刪除、儲存與還原、匯出、多分頁同步、手機版面及儲存失敗保護。預設連至 `http://127.0.0.1:3000` 並使用 `/usr/bin/chromium`；可透過 `LEDGER_TEST_URL` 和 `LEDGER_CHROMIUM` 覆寫。測試截圖輸出至 `/tmp/little-ledger-desktop.png` 與 `/tmp/little-ledger-mobile.png`。

主要檔案：`index.html`（介面）、`styles.css`（樣式）、`app.js`（互動與儲存）、`ledger.js`（資料處理）。原有會議紀錄保留於 `test.md` 與 `week4.md`。
